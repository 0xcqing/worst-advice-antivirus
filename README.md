# worst-advice-antivirus

A dependency-free Node 22 TypeScript program that holds one line of deliberately terrible AI advice and writes it to `entry.txt` as UTF-8, one trailing newline, after validating its length, byte count, word count and flat tone. The line works because it sounds like a tidy troubleshooting step — a confident, harmless-sounding workaround — so a reader follows it before noticing that it switches a defense off right when new files arrive. It keeps the advice inside the 1–140 character gate while staying concrete and followable.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts
```
